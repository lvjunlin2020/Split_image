# Split_image — 图像等分切分工具

Windows 桌面小工具(egui,单 exe 免运行库):选择一张图像或一个文件夹(批量),输入"纵向/横向各切几刀",自动把图像等分切开,以**原文件名为前缀**保存在原图同目录。

## 切分语义(按"刀数"理解)

- **纵向切分数(竖刀)**:在竖直方向切几刀,竖向切线分出左右 → 列数 = 刀数 + 1
- **横向切分数(横刀)**:在水平方向切几刀,横向切线分出上下 → 行数 = 刀数 + 1

例:一张 4 列 × 3 行的拼合图 = 纵向 3 刀 + 横向 2 刀。界面预览区实时显示切分网格与每块编号,所见即所得。

## 功能

- 单文件 / 文件夹批量两种模式,支持把图像直接拖入窗口;批量模式预览文件夹第一张图
- 后台线程切分,进度条 + 日志,可中途停止
- 输出命名 `原名_r行c列.扩展名`(如 `照片_r02c03.jpg`),重跑覆盖同名输出
- 「输出文件夹…」可把切分结果改存到指定目录(默认原图同目录,可一键恢复默认)
- 沿用原格式(JPEG 按质量 95 重编码),不可编码格式自动回退 PNG
- 自动应用 EXIF 方向(手机竖拍照片先转正再切分)
- 非整除尺寸余数归末块(100px 切 3 列 → 33/33/34),整数边界保证切完可无缝拼回原图
- 支持中文文件名;「浏览切分结果」一键打开输出目录;「关于」对话框说明语义与规则

## 命令行模式(供脚本/自动化)

```
Split_image.exe --cli <纵向刀数> <横向刀数> <图像文件或文件夹>... [--out <输出目录>]
```

刀数范围 0~49(0 = 该方向不切);`--out` 不存在时会自动创建;退出码 0 成功、1 有失败文件、2 参数错误。

## 构建

```bash
cargo build --release   # 产物 target/release/Split_image.exe(本仓已含生成的图标资源)
cargo test              # 单元 + 集成测试
```

图标资源由 `assets/icon2.png` 生成:`python make_icon.py` 产出 `assets/icon.ico`(exe 资源)与 `assets/icon_64.rgba`(窗口图标),需 Pillow。两个生成物已提交,克隆后可直接构建;图标源图(`assets/*.png`)体积较大,未入库,如需换图标可自行放置后重新生成。

`testdata/` 内含演示样例:四色图、带 EXIF 方向标记的竖拍图、批量文件夹。

## 项目结构

- `src/lib.rs` — 切分核心逻辑(网格计算、命名、批量流水线),GUI/CLI/测试共用
- `src/main.rs` — egui 图形界面 + `--cli` 命令行入口
- `tests/integration.rs` — 集成测试(JPEG 保持、损坏文件跳过、取消语义等)
